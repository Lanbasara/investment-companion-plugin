# 专业投资报告标准

## 最小结构

不是每个问题都需要完整长报告。材料性研究按以下顺序组织，只保留会改变判断的部分：

1. **结论**：一句话回答问题；给出截至日期与置信度。
2. **关键事实**：最重要的 3–7 项证据，注明来源、日期、单位和口径。
3. **判断链**：解释事实如何支持或反对 Thesis；明确事实与解释的分界。
4. **反方与未知**：列出最强反证、缺口和可观察的失效条件，不堆砌通用风险。
5. **个人组合意义**：说明暴露、相关性、流动性、机会成本，以及为什么现在值得关注或暂时不值得行动。

## 质量门槛

- 使用绝对日期，不用含混的“最近”“当前”。
- 报告数据必须存在可比基准；孤立增长率和孤立估值倍数没有决策意义。
- 不因小数位多而制造精确感。估值用不超过三个真正影响决策的情景。
- 把“好公司”“好资产”“好价格”“适合这个用户”视为四个不同命题。
- 把没有行动作为正式基准方案，而不是报告失败。
- 引用紧邻相关事实；Web 搜索摘要不能替代底层文档。
- 若关键证据过时、缺失或相互冲突，结论必须相应降级。

## 置信度

只使用“高 / 中 / 低”，并解释最主要的限制：

- **高**：关键结论由近期、直接、口径一致的证据支持，反方已被实质检验。
- **中**：主要事实可靠，但至少一个重要驱动仍依赖假设或不完整数据。
- **低**：身份、权限、时效、定义或核心变量存在会改变结论的缺口。
